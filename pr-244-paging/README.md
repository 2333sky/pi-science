## 诚实段

- **与任务书「子菜单左缘被切」不一致**：三档实测子菜单左缘 `l = 109.5 / 144.5 / 154.5`，均 ≥ 0；右缘 `330.5 / 365.5 / 375.5` 也都在视口内（`offscreen` 为空）。额外探针 320 宽：`l = 82.5`，同样没被切。**这批 commit 上可复现的缺陷是「子菜单覆盖父菜单、父菜单条目完全不可见」**，320 宽下子菜单高度还被压到 123px（约 1 行多）。如果 PR 里写「左缘被切」，与本组截图对不上；建议按「覆盖父菜单 / 无 Back」描述。
- **拦截出来的部分**：`/api/model-selection/catalog` 用路由替换成 8 个模型（4 个 provider，档位 off/low/medium/high），否则夹具只有 1 个模型；`390-selected-after` 这一帧额外拦截了 `PUT/GET /api/sessions/visual-session-1/model-selection`（夹具 mock server 没有 PUT handler，不拦截则选择不会持久化、标签会回弹）。其余请求走真 mock server。
- **未覆盖**：深色主题、键盘操作（Esc / Back 键 / 方向键）、真机与触屏手势、超过 50 个模型时的 Previous/Next 分页、搜索框输入过滤、中文本地化文案。
- 只读：两版都在临时 detached worktree（`/tmp/qb` = `3c7cfa4a`、`/tmp/qa` = `3d1dc77f`）里构建，未改动仓库文件、未提交、未推送。
